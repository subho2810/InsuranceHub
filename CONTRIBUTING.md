# Contributing to InsuranceHub

Thank you for your interest in contributing to InsuranceHub.

## Development Workflow

1. Create or select an issue.
2. Create a feature branch.
3. Implement the solution.
4. Update documentation if required.
5. Commit using Conventional Commits.
6. Open a Pull Request.
7. Merge after verification.

## Commit Convention

Examples:

- feat(identity): implement user registration
- fix(payment): correct premium calculation
- docs: update project roadmap
- refactor(policy): simplify validation
- test(claims): add unit tests

## Coding Standards

- Follow Clean Code principles.
- Keep services independent.
- Write meaningful commit messages.
- Update documentation whenever business rules change.

Happy coding!

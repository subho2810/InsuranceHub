# 🛡️ InsuranceHub

> A modern, microservices-based Health Insurance Management Platform built using Spring Boot, React, PostgreSQL, Docker, and Domain-Driven Design (DDD).

---

## 📖 Project Vision

InsuranceHub is an enterprise-inspired Health Insurance Management Platform designed to demonstrate professional software engineering practices from business analysis to deployment.

---

# 🎯 Why InsuranceHub?

Most portfolio projects focus primarily on implementing features. InsuranceHub takes a different approach.

This project is being developed as if it were a real enterprise product, where every implementation begins with understanding the business domain before writing code.

The development process emphasizes:

- Business Requirements Analysis (BRD)
- Functional & Non-Functional Requirements
- Domain-Driven Design (DDD)
- Clean Architecture
- Microservices Architecture
- Event-Driven Communication
- RESTful API Design
- Security by Design
- Documentation-First Development
- Agile Development Practices

The objective is not simply to build an insurance application, but to demonstrate how enterprise software is analyzed, designed, implemented, tested, and maintained throughout its lifecycle.
